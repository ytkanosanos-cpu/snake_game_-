# 🐍 Змейка

Классическая игра «Змейка» в одном HTML-файле. Не нужен интернет, сервер или установка чего-либо.

## Как запустить

**Самый простой способ:** скачайте `index.html` и откройте его двойным кликом — игра откроется в браузере.

Или через терминал:

```bash
git clone https://github.com/ytkanosanos-cpu/snake_game_-.git
cd snake_game_-
open index.html        # macOS
# xdg-open index.html  # Linux
# start index.html     # Windows
```

**В интернете через GitHub Pages:** Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
Через минуту игра будет доступна по адресу `https://ytkanosanos-cpu.github.io/snake_game_-/`.

## Управление

| Клавиша | Действие |
|---|---|
| Стрелки / WASD | Движение |
| Пробел | Пауза |
| Enter | Начать заново |
| Свайпы / кнопки на экране | Управление на телефоне |

С каждым яблоком змейка ускоряется. Рекорд сохраняется в браузере.
